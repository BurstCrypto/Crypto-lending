## Scope and prohibitions

The static scope covers only Ethereum and Solana wallet boundaries. The listed
mainnet network identifiers identify the production behaviors that an
independent reviewer must assess; they do not permit a mainnet connection or
transaction. Execution remains limited to a future, explicitly authorized and
isolated non-production environment using dedicated unfunded test wallets.
Base, other chains, funded wallets, customer or production data, public
deployment, and transaction submission are outside this packet.

The plan covers application-session separation, EVM and Solana ownership-proof
binding, cross-chain/provider isolation, disconnect and revocation behavior,
disabled transaction-capability bypass attempts, privacy, storage, logging, and
egress inspection. It cannot create application login or transaction authority.
