# KAN-255 — Synthetic allocation blends with deferred fees

KAN-255 extends the authenticated zero-egress demo after KAN-254. It changes
only the explicitly guarded local-demo composition; the production KAN-68,
KAN-69, and Smart Yield contracts remain unchanged.

## Product behavior

The idle portfolio reports current, supported, priced capital before a route or
strategy has been chosen. With both fixture wallets, portfolio value and
available buying power are `$11,000.00`. Stale, unsupported, unpriced, and
otherwise ineligible sources still cannot increase buying power. The idle
response contains no hypothetical fee deductions.

The user can preview three deterministic blends:

| Blend          | Liquid reserve | Conservative yield | Balanced yield |
| -------------- | -------------: | -----------------: | -------------: |
| More liquid    |            60% |                30% |            10% |
| Balanced blend |            30% |                45% |            25% |
| More yield     |            15% |                35% |            50% |

Selecting a blend sends its closed preset identifier to the authenticated,
CSRF-protected `POST /api/v1/local-demo/allocation-preview` endpoint. The server
derives every amount from the account-scoped portfolio. Callers cannot supply
an amount, wallet, percentage, fee, or account identifier.

Only the non-reserve portion receives the deterministic one-percent action-cost
estimate. The estimate is split into liquidity, conversion, slippage, network,
and routing categories at 50/10/10/10/20. Largest-remainder allocation keeps
all values in integer cents and makes gross capital, fees, and net planned
capital reconcile exactly.

## Safety boundary

The preview is an in-memory projection. It creates no yield operation, quote,
reservation, ledger entry, transaction, provider request, network request, or
persistent allocation. Every response carries
`use: LOCAL_DEMO_ESTIMATE_ONLY` and
`mayAuthorizeFinancialAction: false`, and the browser repeats that no
transaction was created.

This demo does not complete KAN-176, KAN-181, KAN-184, or KAN-185. Those tickets
remain authoritative for approved opportunity discovery, risk classification,
production allocation plans, and confirmation-bound execution.
